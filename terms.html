Пользовательское соглашение

Настоящее Пользовательское соглашение регулирует использование сервиса AI Marketing Agent.

1. Общие положения

AI Marketing Agent — сервис для анализа, мониторинга и управления цифровой рекламой с использованием технологий искусственного интеллекта.

2. Использование сервиса

Пользователь может подключать рекламные аккаунты и использовать сервис для анализа рекламных кампаний, получения рекомендаций, формирования отчетов и управления рекламой в пределах предоставленных разрешений.

3. Ответственность

AI Marketing Agent не гарантирует определенный уровень продаж, количества заявок, прибыли, ROAS или иных рекламных показателей.

Пользователь самостоятельно отвечает за рекламные аккаунты, предоставленные сервису доступы и законность использования рекламных материалов.

4. Данные

Сервис может обрабатывать данные, необходимые для работы рекламной аналитики и управления рекламными кампаниями, включая данные рекламных аккаунтов, кампаний, расходов и показателей эффективности.

5. Изменение соглашения

Администрация сервиса может изменять настоящее соглашение. Актуальная версия публикуется на данной странице.

6. Контакты

По вопросам использования сервиса обращайтесь по адресу электронной почты, указанному владельцем сервиса.
